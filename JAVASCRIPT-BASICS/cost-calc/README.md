# 🏍️ Fuel Cost Calculator

A functional web utility built to calculate trip expenses, specifically designed with the **Honda CB350** in mind.

### 🛠️ Tech Stack
* **HTML5**: Semantic structure for user inputs.
* **CSS3**: Minimalist styling using the Box Model and Flexbox for a centered UI.
* **Vanilla JavaScript (ES6+)**: Implements DOM manipulation and logic using template literals and `.toFixed(2)` for currency formatting.

### 🚀 Key Features
* **Validation**: Includes logic to check for empty inputs before calculation to prevent errors.
* **Precision**: Rounds total cost to two decimal places for a professional look.
* **User-Centric**: Designed for quick calculations for college commutes or vacations.

### 📖 How to run
1. Clone the repository.
2. Open `Mileage-calc.html` in any modern web browser.
3. Enter Distance, Mileage, and Fuel Price to get the total cost.
